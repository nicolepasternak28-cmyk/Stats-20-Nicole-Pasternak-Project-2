# Stats 20 Project 2: Reproducible Data Analysis

This repository contains my Project 2 presentation for UCLA Stats 20 (Spring 2026). The project demonstrates reproducible statistical analysis using R and Quarto, including data visualization, summary statistics, and structured reporting.

---

## Project Overview

This project explores a real-world dataset using R to perform statistical analysis and visualization. The goal is to demonstrate reproducible workflows by combining code, interpretation, and graphical output in a single document.

Key objectives:
- Import and clean real-world data
- Generate descriptive statistics
- Create meaningful data visualizations
- Apply vectorized operations in R
- Present findings in a reproducible format using Quarto

---

- `Nicole_Pasternak_Project_2.qmd` — main Quarto source file  
- `Nicole_Pasternak_Project_2.html` — rendered presentation slides  
- `data/` — dataset used for analysis (if included)  
- `images/` — external images used in the presentation  
- `README.md` — project description and documentation  

---

## Methods & Analysis

The analysis includes:

- Data import and structure inspection
- Summary statistics (mean, median, variance, etc.)
- Data visualization using R plotting tools
- Vectorized transformations for efficient computation
- Integration of external images for contextual understanding

All results are fully reproducible using the provided Quarto file.

## Tools Used

- R
- Quarto (RevealJS presentation format)
- ggplot2 / base R graphics
